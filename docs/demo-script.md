# Demo script

1. Sign in as the customer and open Home to show API-delivered news, products, discounts, loyalty, active reports, and branches.
2. Submit a report and note its tracking number.
3. Sign in to admin as the branch administrator, open the new case, verify it, assign Operations, and move it to In progress then Resolved.
4. Return to the customer report detail and show the shared status timeline.
5. Run the vision simulator to demonstrate persistence opening an incident, a clear period auto-resolving it, and admin reopen.
