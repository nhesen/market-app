# Design reference analysis

No image reference files were present in the workspace or attachment set. This foundation therefore follows the written reference authority: bright surfaces, navy hierarchy, vivid blue actions, restrained purple for AI-originated events, semantic green/amber/red statuses, rounded bordered cards, and generous whitespace.

The mobile experience adapts this into a daily retail assistant rather than a complaint app: information and offers precede active reports, while the central report action remains obvious. The admin experience adapts it into a light operational case system with source badges, an evidence/timeline main column, and assignment controls alongside it. Status never relies on colour alone.

Tokens live in `mobile/constants/theme.ts` and `admin/src/styles/tokens.css`. Both use the same names and meanings even though they are platform-native implementations.
