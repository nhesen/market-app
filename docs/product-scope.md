# MVP scope

Core: authentication/RBAC, tenant and branch isolation, customer home content, report-to-incident workflow, admin verification/status changes, customer timeline, and deterministic camera persistence/auto-resolution/reopen.

Prepared or staged: staff audit domain, content CRUD, richer analytics, uploads, push notifications, and optional OCR. Non-goals remain checkout, payments, POS/ERP, facial recognition, theft accusation, cross-market comparison, and production ML training.
